# Scope Discipline

- Implement only what was explicitly requested. Do not add features, refactors, files, or abstractions beyond the stated task.
- Do not "improve" adjacent code, rename things, or reformat unrelated files.
- If a change seems necessary but was not requested, ask before doing it.
- Prefer the smallest diff that satisfies the request.
- When in doubt, ask (grill-me) rather than guess.
- Do not run extra verification or create helper scripts beyond what the task requires.
