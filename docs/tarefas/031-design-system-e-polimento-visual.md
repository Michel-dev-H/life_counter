# 031 — Design system e polimento visual

- **Status:** Pendente
- **Área:** UX/UI
- **Prioridade:** Alta

## Objetivo

Unificar os padrões visuais e elevar a arena de uma interface funcional para uma ferramenta mobile refinada, sem prejudicar a velocidade de jogo.

## Escopo

- Estabelecer tokens, tipografia, espaçamento, hierarquia, estados e padrões de ícones.
- Reutilizar componentes quando houver padrão real, evitando abstrações prematuras.
- Eliminar aparência de formulário administrativo ou calculadora genérica.
- Usar efeitos luminosos, gradientes e animações com moderação.
- Revisar distribuição, contraste, responsividade e feedback em telas reais.
- Manter consistência entre lobby, arena, overlays e configurações.

## Critérios de aceite

- [ ] A interface comunica claramente valor de PV, participante e ação.
- [ ] Controles críticos são confortáveis durante uma partida presencial.
- [ ] Os três temas preservam linguagem e componentes coerentes.
- [ ] Nenhum placeholder ou botão sem comportamento é tratado como concluído.
- [ ] A validação inclui capturas/revisão em viewports móveis.
