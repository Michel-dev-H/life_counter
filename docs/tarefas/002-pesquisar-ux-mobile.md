# 002 — Pesquisar companions e UX mobile

- **Status:** Pendente
- **Área:** Descoberta e UX
- **Prioridade:** Média

## Objetivo

Identificar padrões úteis de ferramentas companion e interfaces usadas em partidas presenciais, sem copiar identidade visual ou conteúdo protegido.

## Escopo

- Avaliar referências de companions existentes e boas práticas para uso compartilhado sobre uma mesa.
- Considerar legibilidade à distância, uso com uma mão, alvos de toque, orientação, brilho e poucos passos.
- Registrar oportunidades e riscos sem ampliar o produto para simulador completo.
- Usar referências como inspiração funcional, não reproduzir telas, marcas ou artes.

## Critérios de aceite

- [ ] O registro distingue observações de decisões de design do projeto.
- [ ] Há diretrizes de legibilidade e interação para telas pequenas e partidas presenciais.
- [ ] Nenhum recurso protegido é copiado para o aplicativo.
- [ ] As conclusões alimentam as tarefas de design, layout e navegação.
